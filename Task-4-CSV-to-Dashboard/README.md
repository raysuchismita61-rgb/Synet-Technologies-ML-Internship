# Task 4: CSV to Dashboard

## Objective

The objective of this task is to transform CSV data into an interactive dashboard that presents important information through charts, graphs, and summary metrics.

## Tasks Performed

* Loaded the CSV dataset
* Inspected and analyzed the dataset
* Cleaned and prepared the data for visualization
* Selected relevant features and metrics
* Created interactive visualizations
* Designed a dashboard to present key insights
* Added charts and summary information
* Analyzed the results obtained from the dashboard

## Dashboard Features

The dashboard includes:

* Key Performance Indicators (KPIs)
* Bar Charts
* Line Charts
* Pie/Donut Charts
* Data tables
* Interactive filters, where applicable

## Technologies Used

* Python
* Pandas
* Plotly / Streamlit
* CSV
* VS Code

## Files

* `dataset.csv` — CSV dataset used for the dashboard
* `dashboard.py` — Dashboard application code
* `README.md` — Project documentation

## How to Run

Install the required libraries:

```bash
pip install pandas plotly streamlit
```

Run the dashboard using:

```bash
streamlit run dashboard.py
```

The dashboard will open in a web browser.

## Outcome

The CSV dataset was converted into an interactive dashboard that makes the data easier to understand through visualizations, KPIs, and interactive analysis.

## Conclusion

The dashboard provides a clear and interactive way to explore the dataset and identify important trends and business insights.
