# Task 2: Exploratory Data Analysis (EDA)

## Objective

The objective of this task is to perform Exploratory Data Analysis (EDA) to identify trends, patterns, relationships, and important insights from the dataset.

## Tasks Performed

* Loaded the dataset using Pandas
* Examined the structure and dimensions of the dataset
* Generated summary statistics
* Checked for missing values
* Analyzed numerical and categorical features
* Performed correlation analysis
* Identified important trends and patterns
* Created data visualizations
* Derived meaningful insights from the dataset

## Visualizations

The following visualizations were used:

* Bar Chart
* Histogram
* Scatter Plot
* Correlation Heatmap

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code

## Files

* `dataset.csv` — Dataset used for the analysis

## Outcome

The analysis provides useful insights into the dataset by identifying statistical relationships, trends, distributions, and patterns through numerical analysis and graphical visualization.
