# Task 3: Exploratory Data Analysis (EDA)

## Objective

The objective of this task is to analyze the dataset using Exploratory Data Analysis (EDA) techniques and identify meaningful trends, patterns, relationships, and insights.

* Inspected the dataset structure

* Checked for missing values

* Identified trends and patterns
* Created different data visualizations
